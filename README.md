  <summary><b>🇬🇧 English Documentation (Click to expand/collapse)</b></summary>
  <br>

  **ArvinX RTLify** is a powerful, lightweight, and smart Chrome extension that transforms any web page into a Right-to-Left (RTL) layout with a single click. Designed specifically for Persian/Arabic speakers, it handles complex layouts, code blocks, and embedded frames intelligently.

  ### ✨ Key Features
  * **One-Click Toggle:** Switch between LTR and RTL instantly.
  * **Smart Domain Memory:** Remembers your choice for each website. If you make a site RTL, it stays RTL on your next visit.
  * **Code Block Protection (v2.2.0):** Automatically detects code blocks, syntax highlighting, and technical inputs, keeping them LTR so your code never breaks.
  * **Beautiful Popup UI:** A clean, intuitive menu to manage settings and check the current domain's status.
  * **Keyboard Shortcut:** Press `Alt + Shift + R` to toggle RTL without touching the mouse.
  * **100% Privacy:** No data collection, no tracking, no remote code. Everything runs locally on your machine.

  ### 📥 Installation

  **Method 1: Install via ZIP (Recommended for Windows & Mac)**
  1. Go to the [Releases](https://github.com/A-soheilyfar/ArvinX-RTLify/releases) page and download the latest `.zip` file.
  2. Extract the downloaded file.
  3. Open Chrome and go to `chrome://extensions`.
  4. Enable **Developer mode** (top right corner).
  5. Click **Load unpacked** and select the extracted folder.
  6. Pin the extension to your toolbar. Done!

  **Method 2: Install via CRX (Linux only)**
  * Download the `.crx` file from Releases and drag & drop it into the `chrome://extensions` page.
  * ⚠️ **Warning:** Chrome on Windows and macOS blocks direct CRX installations for security reasons. Please use Method 1.

  ### 🛠️ Usage
  * **Click** the extension icon to open the popup and toggle RTL.
  * **Right-click** anywhere on a page and select "Toggle RTL".
  * Use the shortcut **`Alt + Shift + R`**.

  **ArvinX RTLify** یک افزونه قدرتمند، سبک و هوشمند برای مرورگر کروم است که با یک کلیک، هر وب‌سایتی را به حالت راست‌به‌چپ (RTL) تبدیل می‌کند. این افزونه مخصوص فارسی‌زبانان طراحی شده و چیدمان‌های پیچیده، بلاک‌های کد و آی‌فریم‌ها را به خوبی مدیریت می‌کند. توسعه یافته توسط **Arvin X Team**.

  ### ✨ ویژگی‌های کلیدی
  * **تغییر جهت با یک کلیک:** جابه‌جایی فوری بین حالت LTR و RTL.
  * **حافظه هوشمند دامنه:** انتخاب شما برای هر سایت به خاطر سپرده می‌شود. اگر سایتی را RTL کنید، در مراجعه بعدی هم RTL می‌ماند.
  * **محافظت از بلاک‌های کد (نسخه 2.2.0):** بلاک‌های کد، سینتکس‌های برنامه‌نویسی و فیلدهای فنی به صورت خودکار شناسایی شده و چپ‌چین (LTR) می‌مانند تا کدهای شما به هم نریزد.
  * **رابط کاربری زیبا (Popup):** یک منوی تمیز و آسان برای مدیریت تنظیمات و مشاهده وضعیت سایت فعلی.
  * **میانبر صفحه‌کلید:** با فشردن `Alt + Shift + R` می‌توانید بدون استفاده از موس جهت صفحه را تغییر دهید.
  * **حریم خصوصی ۱۰۰٪:** هیچ اطلاعاتی جمع‌آوری یا ارسال نمی‌شود. تمام کدها به صورت محلی روی سیستم شما اجرا می‌شوند.

  ### 📥 راهنمای نصب

  **روش اول: نصب با فایل ZIP (پیشنهادی برای ویندوز و مک)**
  1. به صفحه [Releases](https://github.com/A-soheilyfar/ArvinX-RTLify/releases) بروید و آخرین نسخه فایل `.zip` را دانلود کنید.
  2. فایل دانلود شده را از حالت فشرده خارج کنید.
  3. مرورگر کروم را باز کنید و به آدرس `chrome://extensions` بروید.
  4. در گوشه بالا سمت راست، گزینه **Developer mode** (حالت توسعه‌دهنده) را روشن کنید.
  5. روی دکمه **Load unpacked** کلیک کنید و پوشه‌ای که خارج کردید را انتخاب کنید.
  6. آیکون افزونه را در نوار ابزار Pin کنید. تمام!

  **روش دوم: نصب با فایل CRX (فقط برای لینوکس)**
  * فایل `.crx` را از بخش Releases دانلود کرده و در صفحه `chrome://extensions` رها (Drag & Drop) کنید.
  * ⚠️ **هشدار:** مرورگر کروم در ویندوز و مک به دلایل امنیتی، اجازه نصب مستقیم فایل‌های CRX را نمی‌دهد. لطفاً از روش اول استفاده کنید.

  ### 🛠️ نحوه استفاده
  * روی **آیکون افزونه** کلیک کنید تا پاپ‌آپ باز شود و RTL را روشن/خاموش کنید.
  * در هر جای صفحه **راست‌کلیک** کنید و گزینه "تغییر حالت RTL" را انتخاب کنید.
  * از میانبر صفحه‌کلید **`Alt + Shift + R`** استفاده کنید.
